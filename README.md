# Sites

Коллекция небольших статических сайтов и прототипов. Каждый лежит в своём HTML-файле и открывается в браузере без сборки.

| Файл | Что это |
|---|---|
| [`index.html`](index.html) | WebAR-сканер объектов в пространстве (прототип) |
| [`iwbhappyCard/`](iwbhappyCard) | Сайт-визитка: главная, «обо мне», проекты, контакты, светлая и тёмная темы |
| [`card.html`](card.html) | Первая версия сайта-визитки |
| [`ReSkills.html`](ReSkills.html) | ReSkills: лендинг AI-анализа карьеры |
| [`finance.html`](finance.html) | Страница учёта финансов |
| [`quiz.html`](quiz.html) | Тест по истории |
| [`economics-exam.html`](economics-exam.html) | Тренажёр для подготовки к экзамену ОЭП |
| [`philosophy-quiz.html`](philosophy-quiz.html) | Тренажёр по философии |

## Стек

HTML, CSS, JavaScript, Tailwind CSS (CDN).

## Запуск

Откройте нужный файл в браузере.
